# RyzikChat 🦊

Мессенджер для Android (позже — Windows) со своим сервером, сквозным шифрованием и дизайном Material You.

- `android/` — приложение: Kotlin + Jetpack Compose + Material 3 (цвета из обоев на Android 12+).
- `server/` — собственный API: Node.js, REST + WebSocket, SQLite. Подробности в [server/README.md](server/README.md).

## Что уже есть

- Экран «Привет!» с листаемыми страницами про мессенджер, кнопка «Войти» внизу.
- Вход и регистрация; нажимая кнопку, пользователь соглашается с Правилами использования (ссылка на экран правил).
- Личные чаты, группы, «Избранное» (сохранённые сообщения).
- Текст, фото, видео, любые файлы; просмотр фото с зумом, видеоплеер.
- Ответы (в т.ч. свайпом), пересылка, редактирование, удаление, реакции (двойное касание — быстрая реакция).
- «Печатает…», «в сети / был(а)», галочки прочтения, закрепление, архив, без звука, поиск.
- Бейджи рядом с именем: создаёт и выдаёт **только администратор** (админ-панель + управление в профиле).
- Сквозное шифрование: X25519 + HKDF + AES-256-GCM для сообщений, AES-CTR + HMAC для файлов. Ключ хранится в Android Keystore. Сервер видит только шифротекст.
- Настройки: тема, Material You, 8 цветов, AMOLED, обои, размер текста, скругление пузырей, анимации, уведомления, приватность, сеансы, смена пароля, кэш, адрес сервера.
- Много анимаций: пружинки, появление сообщений, плавная смена темы, переходы между экранами.

## Как получить APK

GitHub Actions собирает APK при каждом пуше в `main` (вкладка **Actions → Сборка → артефакт RyzikChat-apk**).
Для релиза поставьте тег: `git tag v0.1.0 && git push --tags` — APK появится в Releases.

Локально: `cd android && ./gradlew assembleRelease` (нужен Android SDK).

## Как запустить

1. Запустите сервер (см. `server/README.md`) на компьютере или VPS.
2. Установите APK, нажмите «Войти» → «Сервер» и укажите адрес, например `http://192.168.1.10:8080`.
3. Первый зарегистрированный аккаунт становится администратором.
